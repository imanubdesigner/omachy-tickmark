# Roadmap

A loose list of ideas for Tickmark. I update it every now and then, when I have the time and the inspiration, so treat it as a notebook rather than a promise. Nothing here has a date.

## Maybe

- **Settings**: options such as turning off the count in the icon, or changing how many items the bin keeps (now 50). Omarchy declares plugin options in the manifest (`barWidget.schema`) and applies them per widget instance; I want to check the exact format before using it.
- **Custom file location**: a setting for where the todo file lives, so the list can sit in a synced folder (Syncthing, Obsidian vault, and so on). It touches the manifest and the panel, so it is not a quick change.

## Not planned

- Sync, due dates and multiple lists. Tickmark is meant to stay small and stay out of the way.
